## 2. 出现的问题（按影响排序）

### P1 · 翻译范围是"整页可见文本"，正文只占额度的一小部分

MDN 的 CSS grid 页最典型：送出 **477 段**，其中

- **188 段是 ≤12 字符的碎片**：`JS reference`、`HTML DOM API`、`Technologies`、`Grid layout`、
  `Scroll snap`、`Paged media`、`Inheritance`、`Product help`…… 全部来自**左侧导航与侧栏目录**；
- **只有 8 段是真正的正文**（>120 字符的散文）。

也就是说这一页约 **98% 的额度花在正文之外**。同类：w3schools 265 段、theverge 首页 258 段、
stackoverflow 723 段。

对照：**沉浸式翻译默认只翻"页面核心内容区（正文、帖子内容）"，导航/页头页脚默认跳过，
"翻译整页"是用户手动切换的兜底**（官方 FAQ 明确写了这一点）。TransLens 没有这一层——
`extractor` 的判据是"可见 + 有文本 + 非黑名单标签"，没有"正文区域"概念。

这不是 bug，是产品定位差异，但它决定了真实使用成本：**同一篇 MDN，TransLens 的 token 消耗
可能是沉浸式翻译的 20~50 倍**。README 目前没有任何一处说明这一点。

### P2 · 代码标识符被当成自然语言送进接口

w3schools 上送出的段里有整整 12 条 HTML 标签名：
`<table>` `<tr>` `</tr>` `<th>` `<td>` `<caption>` `<colgroup>` `<col>` `<thead>` `<tbody>` `<tfoot>`。
溯源结果（文本节点的祖先链）：

```
<td>   ← code.w3-codespan < p < div.w3-col < div.w3-row < div.w3-main
<table> ← a < span < td < tr < tbody
```

即**行内 `<code>` 单独构成一个段落时，整段就是这段代码**。README 隐私一节写的是
「`<script>`、`<style>`、`<code>`、`<pre>` …… 一律跳过」，实测只做到了"不往 code 里插译文宿主"，
没做到"不把 code 的文本送出去"。

MDN 上同一形态更成问题：侧栏里的 CSS 属性名 `background-*`、`overscroll-*`、`transition-*`
被当散文送出。这类字符串一旦被模型"翻译"，用户看到的会是 `背景-*` 这种废掉的东西。

### P3 · 屏幕阅读器专用（sr-only）文本被翻译

- MDN：`Skip to main content` → 送出并渲染成「跳至主要内容」；
- arxiv：`Skip to main content` 同样被送出。

这类元素用 `clip` / 1px 尺寸隐藏，既不是 `display:none` 也不是 `aria-hidden`，所以躲过了可见性闸门。
用户永远看不到它们，但额度花了。与 README「只有在网页里**可见**的文本才会被送去翻译」不符。

### P4 · 中文页并非"零请求"

README 的手动验收清单第 10 条写：「打开一个中文页面 → 翻译 → 提示没有找到需要翻译的内容，**不发翻译请求**」。
实测：

- GNU 中文页送出 7 段，人民网送出 3 段（1 个请求）。
- 内容本身合理（页面确有英文残留），但**与文档承诺不符**，验收清单这一条走不通。
- 其中一条值得单独提：`翻译：邓楠 <邮箱已隐去>，2015。` —— **邮箱地址被发往第三方翻译接口**。
  （**入库前已隐去**：原读数里是一个真实存在的邮箱地址，来自该页面的公开引用。这里保留它的**形状**
  而不保留那个地址本身——要钉住的判据是"邮箱形状的文本会被发往接口"，与具体是谁的地址无关。）
  它是页面公开文本，不算越界采集，但 README 隐私一节说"不采集任何浏览数据"，
  用户看到这条会合理期待有个 `translate="no"` 或邮箱保护的处理。

### P5 · 元数据、时间戳、URL 被当作段落

arxiv 论文页 72 段里，正文只有标题+摘要+作者 3 段左右，其余是：

```
[v1] Wed, 15 Mar 2023 17:15:04 UTC (3,853 KB)     ← 6 条版本时间戳各成一段
https://doi.org/10.48550/arXiv.2303.08774          ← DOI 整段送去翻译
cs.CL · cs.AI · cs · NASA ADS · Log in · Donate    ← 单字符/缩写/导航标签
Which authors of this paper are endorsers? | Disable MathJax (What is MathJax?)
```

### P6 · 竖线拼接的多个链接被合成一段

人民网：`Follow Xi|跟着总书记学党史|中央文件` 作为**一段**送出。这是同一容器里的松散文本，
三个独立链接的文本被拼成一句喂给模型，结果必然是糊的。

### P7 · 大页面收敛极慢，等待期"看起来像卡死"（真机，你那份档案）

MDN 214 段的页面，从按 Alt+T 起 **10 分钟后**视口内仍有上百段停在「翻译中…」，期间
**不报错、不给重试按钮、没有 toast**。

**这条的归因已经改写（2026-09-23 补测）。** 我一度由「>10 分钟 ÷ 6 波」反推出
"单请求 ≈100 秒"，并据此写过"每一批都在超时线附近"。**那个推算是错的**，直接测量推翻了它：

- 真接口实测（`.qa/measure-latency.mjs`）：L₁ = 1489ms / 37 tok，L₁₂ = 5236ms / 296 tok
  ⇒ 拟合 **固定开销 ≈950ms + ≈14.5ms/token（≈69 tok/s）**；`completion_tokens` 与中文译文
  应有量相符 ⇒ **不是推理模型，没有思考链在烧时间**。
- 用这个画像在真 Chrome 里跑同一页（`.qa/run-why-slow.mjs`）：**总时长 10.1 秒**（98 段 / 9 批）。
- 翻译中途把标签页切到后台再跑：**9.1 秒**，与前台无差别 ⇒ 不是隐藏页节流。

⇒ "10 分钟"既不是接口延迟、也不是本地管线（假引擎下 215 段全链路 0.8 秒）、也不是后台节流。
剩下的候选只有两个，且都要在**真会话**里才能分辨：

1. **429 退避风暴** —— 每次重试 500ms + 1500ms 后整批重发，页面上与排队态长得一模一样；
2. **标签页被 Chrome 冻结/丢弃** —— 此时内容脚本的定时器一次都不跑，连超时都不会触发，
   宿主就永久停在「翻译中…」、无错误无重试按钮。**这条与观察最吻合**，也解释了为什么
   `BACKGROUND_TIMEOUT_MS`（本轮已改为随批缩放）对它完全无效。

README「已知限制」里没有一条提到"大页面是分钟级、期间会大面积显示翻译中"。

### P8 · 宿主数远超可见段落数，译文在视觉上碎片化

MDN 583 个宿主 vs 275 个可见语义段；w3schools 325 vs 84；lobsters 157 vs 73。
表格每个单元格、侧栏每个链接、每个列表项各插一个宿主。设计上没错（译文要贴着原文落点），
但配合 P1 就变成：**整页密布的碎片译文**，第一眼的观感比沉浸式翻译的"正文双语对照"重得多。

## 4. 台架限制（如实说明）

- 这台机器的网络到不了 `en.wikipedia.org`、`news.ycombinator.com`、`www3.nhk.or.jp`、
  `bbc.com`、`v2ex.com`、`mathworld.wolfram.com`（curl 全部超时），这些站点**未覆盖**。
- stackoverflow 撞上 Cloudflare「Just a moment」挑战页，只拿到送出段数（723），未拿到结构读数。
- `可见语义段` 是我按 `p/li/h1-4/td/th/figcaption/button` + 尺寸与 `display` 过滤的**近似度量**，
  在 paulgraham、w3schools 这类不用语义标签的老布局上会低估（所以它们的"宿主/可见"倍数不可当结论）。
  P1 的结论建立在**送出文本本身可逐条回放**上，不依赖这个度量。
- 本轮为无人值守，用了预授权 dist 副本；真实权限路径（点保存才申请、未授权报 AUTH 且零请求）
  在第一轮已单独验证通过。

## 5. 还差的对照实测（需要你 3 下点击）

要把 §3 里 📄 的部分变成真读数，请在你的 Chrome 里对**同一个页面**
（建议 `https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_grid_layout`）依次做：

1. 右键 → **翻译为中文**（Chrome 原生），完成后说一声 → 我读 DOM，看它替换了什么、跳过了什么；
2. 右键 → **显示原文**还原；
3. 若装了**沉浸式翻译**：用它翻同一页（默认设置即可），说一声 → 我读它的落点与范围。
