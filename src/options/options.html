翻译引擎

状态点的语义（三态，不粉饰）

绿 = 最近一次「测试连接」通过；灰 = 从没测过 （不代表可用，也不代表不可用）；红 = 最近一次测试失败，悬停显示失败原因。 填了 API Key 不等于能用，所以这里不按"填没填"点灯。

记录保存在 chrome.storage.session 里（只有引擎名与成败原因，不含 Key）， 浏览器关闭就没了——重启后所有点回到灰，重新测一次即可。

一个档案 = 一份接口地址 + 一份模型清单 + API Key（走 OpenAI 兼容协议，可接 OpenAI、DeepSeek、 硅基流动、Ollama 等）。点某一行右侧的「编辑」展开：在那里把模型加进清单（手填，或点 「⟳ 获取可用模型」从接口拉一份回来勾选），并把其中一个设为「当前」。配好几个档案后，在 弹窗的「翻译引擎」下拉里按名字直接切换；某个档案有 2 个以上模型时， 弹窗里会多出一个模型下拉。每个档案的访问授权在点该档案的「保存」时按它自己的地址申请 （Chrome 要求用户手势）。

语言与显示

「仅译文」只显示译文（原文被隐藏，按 Alt+T 可还原）；「双语对照」在每段原文下方插入译文。 仅译文模式下译文里的链接：一段里只有一个链接、且它的文字占该段六成以上时（例如整行标题、作者署名行）， 链接仍可点击；一段里有多个链接、或链接文字不足六成时（正文段落常见）， 链接仍可能失去下划线与可点击；链接地址不合规时也会降级为纯文本。 要读原文请按 Alt+T 还原，或在弹窗里切「双语对照」后重新翻译。 改动即时保存；已经翻译过的页面要重新翻译才会换过来。

快捷翻译

快捷键与右键菜单 Alt+T 翻译整页 · Alt+Shift+点击 诊断这块为什么没翻

快捷键由浏览器管理，扩展改不了它——「去浏览器设置」打开的是 Chrome 自己的快捷键页。 两个开关改动即时保存；已经打开的页面会当场重挂监听器，页面没回应时重新加载一次即可。

术语表

强制按你指定的译法翻译，优先于自动判断。一行一条：左边原文、右边译文；改完即生效。

只填一半的行不会保存——一行里原文与译文都填上，它才会写进存储。

站点规则

按域名决定整页翻不翻，自上而下匹配，第一条命中即生效。

规则只认两种写法：example.com（精确，不含子域）与 *.example.com （含裸域与任意层子域）。填整条网址也行——失焦时会规范化成域名；带端口、带路径、光杆 * 这类写法会被当场拒绝并说明原因，不会静默失效。

这个区块的边界（如实说明）

只提供「永不翻译」这一个动作：本扩展还没有自动翻译，「总是翻译」今天不产生任何可观察行为， 所以不给它入口，等自动翻译落地再补。

划词与悬停翻译不受约束——那是你主动发起的单段翻译，与"这个站整页不该翻"是两件事。

还有一处缝：规则的闸只装在整页翻译的入口上，所以已经翻译过的页面 再加规则时，已经翻好的内容与之后新出现的内容都不会被撤掉——要立刻生效请先按 Alt+T 还原再重新翻译。

隐私

逐条写清边界：本地存储、零网络请求、只采集可见文本、授权按需申请。

  • API Key 只存在本机（chrome.storage.local）： 不上传、不同步、不写入日志。档案编辑框的 Key 输入框永远从空开始 （留空保存即保留原 Key），密钥不会渲染进本页 DOM。发给内容脚本的设置是类型级投影—— 投影结果里每个档案都没有这个字段，下游代码拿不到它；内容脚本又运行在浏览器的 isolated world， 页面脚本读不到它的内存。
  • 除翻译请求本身外，不发起任何网络请求：不采集浏览数据，不做任何统计上报。
  • 只有网页里可见的文本才会被送去翻译；不可见区域与 contenteditable 可编辑区域（你正在写、还没保存的草稿）一律不采集。
  • 每个档案接口地址的访问权限只在你点该档案的「保存」时按需申请， 授权范围限定为那个地址的域名；免费引擎不需要额外授权。
密钥隔离做到哪一步（如实说明）

这是"字段隔离 + isolated world"，不是内存级隔离——读取设置的瞬间， 密钥仍会随整份设置经过扩展自己的 isolated world 堆。彻底的结构性隔离要把密钥拆成 独立存储键，属后续工作。
