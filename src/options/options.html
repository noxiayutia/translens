翻译引擎

一个档案 = 一份接口地址 + 模型名 + API Key（走 OpenAI 兼容协议，可接 OpenAI、DeepSeek、 硅基流动、Ollama 等）。配好几个后，在弹窗的「翻译引擎」下拉里按名字直接切换。 每个档案的访问授权在点「保存档案」时按它自己的地址申请（Chrome 要求用户手势）。

语言与显示

「仅译文」只显示译文（原文被隐藏，按 Alt+T 可还原）；「双语对照」在每段原文下方插入译文。 仅译文模式下译文里的链接：一段里只有一个链接、且它的文字占该段六成以上时（例如整行标题、作者署名行）， 链接仍可点击；一段里有多个链接、或链接文字不足六成时（正文段落常见）， 链接仍可能失去下划线与可点击；链接地址不合规时也会降级为纯文本。 要读原文请按 Alt+T 还原，或在弹窗里切「双语对照」后重新翻译。 改动即时保存；已经翻译过的页面要重新翻译才会换过来。

缓存与请求

清除翻译缓存同时清掉会话层与持久层，之后所有页面都要重翻一次

缓存里存的是原文与译文，不含 API Key。「清除」会同时清掉会话层与持久层两层缓存， 清完后所有页面都要重新翻译一次（报出的条数是两层合计）。

隐私

逐条写清边界：本地存储、零网络请求、只采集可见文本、授权按需申请。

  • API Key 只存在本机（chrome.storage.local）： 不上传、不同步、不写入日志。档案编辑框的 Key 输入框永远从空开始 （留空保存即保留原 Key），密钥不会渲染进本页 DOM。发给内容脚本的设置是类型级投影—— 投影结果里每个档案都没有这个字段，下游代码拿不到它；内容脚本又运行在浏览器的 isolated world， 页面脚本读不到它的内存。
  • 除翻译请求本身外，不发起任何网络请求：不采集浏览数据，不做任何统计上报。
  • 只有网页里可见的文本才会被送去翻译；不可见区域与 contenteditable 可编辑区域（你正在写、还没保存的草稿）一律不采集。
  • 每个档案接口地址的访问权限只在你点该档案的「保存档案」时按需申请， 授权范围限定为那个地址的域名；免费引擎不需要额外授权。
密钥隔离做到哪一步（如实说明）

这是"字段隔离 + isolated world"，不是内存级隔离——读取设置的瞬间， 密钥仍会随整份设置经过扩展自己的 isolated world 堆。彻底的结构性隔离要把密钥拆成 独立存储键，属后续工作。
