浸译 设置

翻译引擎

语言与显示

「仅译文」只显示译文（原文被隐藏，段落里的链接点不了，按 Alt+T 可还原）；「双语对照」在每段原文下方插入译文。 改完记得点上面的「保存」；已经翻译过的页面要重新翻译才会换过来。

翻译缓存

缓存里存的是原文与译文，不含 API Key。清除后所有页面都需要重新翻译一次。

隐私

  • API Key 只存在本机（chrome.storage.local）：不上传、不同步、 不写入日志，也不会进入发给网页的设置投影——内容脚本拿到的设置里根本没有这个字段。
  • 除翻译请求本身外，不发起任何网络请求：不采集浏览数据，不做任何统计上报。
  • 自定义接口地址的访问权限只在你点「保存」时按需申请，授权范围限定为 你填的那个域名；免费引擎不需要额外授权。
  • 只有网页里可见的文本才会被送去翻译；不可见区域与 contenteditable 可编辑区域（你正在写、还没保存的草稿）一律不采集。
